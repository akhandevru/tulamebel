# Шаблон сайта мебельного магазина (React + Vite)

Весь контент в одном файле: **`src/config.js`**. Компоненты трогать не нужно.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:5173. Правки в `src/config.js` применяются сразу, без перезапуска.

Готовая сборка для хостинга:

```bash
npm run build
```

Файлы окажутся в папке `dist/`. Посмотреть сборку локально: `npm run preview`.

## Как поменять всё одним промтом

1. Положите свои фото в папку `public/images/` (например `sofa-1.jpg`, `hero-1.jpg`).
2. Скопируйте промт ниже в Claude, заполните, отправьте.

```text

Бренд: название «___», подпись «___», логотип /images/logo.svg (или оставь текстовый).
Цвета: акцент ___, фон ___ (или оставь как есть).
Контакты: телефон ___, почта ___, адрес ___, часы ___,
WhatsApp ___, Telegram ___, Instagram ___, ВК ___.
Заявки отправлять в: WhatsApp / Telegram / почту / formspree (endpoint ___).
Валюта: ___.

Главный экран, слайды:
1) фото /images/hero-1.jpg, заголовок «___», подзаголовок «___»
2) ...

О компании: заголовок «___», текст «___», цифры: ___.

Категории: ___ (фото /images/cat-*.jpg).

Товары (название, категория, цена, старая цена, бейдж, фото, описание, характеристики):
- ___
- ___

```

Всё, что не указано в промте, останется как было.

## Что где в `src/config.js`

| Раздел | Что меняет |
|---|---|
| `brand` | название, подпись, логотип, иконка вкладки |
| `seo` | заголовок вкладки, описание для поисковиков и превью в мессенджерах |
| `theme` | цвета, шрифты (Google Fonts с кириллицей), заголовки прописными, скругление углов |
| `contacts` | телефон, почта, адрес, часы, мессенджеры, соцсети, адрес для карты |
| `sections` | порядок блоков; удалите строку — блок пропадёт |
| `nav` | пункты меню |
| `hero` | слайды главного экрана, кнопки, скорость автопрокрутки |
| `about` | текст о компании, фото, цифры |
| `categories` | категории (связаны с товарами через `id`) |
| `products` | товары: цена, старая цена, бейдж, фото, описание, характеристики. Размер для карточки берётся из характеристики «Размер», «Габариты», «Спальное место» или «Высота» |
| `showcase` | большие блоки «фото на весь экран и текст» |
| `advantages`, `process`, `reviews`, `faq` | преимущества, этапы, отзывы, вопросы |
| `contact` | текст блока заявки, куда уходит заявка, карта |
| `footer` | текст подвала, реквизиты, ссылки |

Фото: ссылка из интернета (`"https://…"`) или свой файл из `public/images/` (`"/images/sofa.jpg"`).

## Куда приходят заявки

`contact.formMode` в `src/config.js`:

- `"whatsapp"` открывает WhatsApp с готовым текстом заявки (по умолчанию)
- `"telegram"` открывает чат в Telegram, текст копируется в буфер обмена
- `"email"` открывает почтовую программу
- `"formspree"` отправляет заявку на почту без перехода. Зарегистрируйтесь на formspree.io и вставьте ссылку в `formEndpoint`

## Публикация

Выполните `npm run build` и загрузите папку `dist/` на любой хостинг: Vercel, Netlify, GitHub Pages, обычный хостинг по FTP. Vercel и Netlify умеют собирать проект сами: укажите команду `npm run build` и папку `dist`.

## Файлы

```
src/config.js          ВЕСЬ контент и настройки
src/App.jsx            порядок секций, окна, общее состояние
src/components/        секции сайта
src/lib/site.jsx       помощники: ссылки, цены, размеры
src/lib/theme.js       применение цветов и шрифтов из config.js
src/styles.css         стили
public/images/         ваши фото
legacy-static/         прежняя версия без React, можно удалить
```
